# Ethan True Hawkes portfolio

The desktop site is in `dist/`. Open `dist/index.html` directly or serve `dist/` with any static file server. No dependencies or build step are required.

- `index.html` contains the page sections and PDF destinations.
- `styles.css` contains the layout, typography, and interaction styles.
- `portfolio.js` handles the R shortcut for the resume.
- `assets/` contains the local Figma artwork, icons, and font files.
- `documents/` contains the two supplied case studies and the resume.
